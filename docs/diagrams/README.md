# 図の一覧

flow-hub の設計と仕様を、図で表したものです。図は [Mermaid](https://mermaid.js.org/) で書いているので、GitHub ではそのまま図として表示されます。

- 仕様の正は [domain.md](../domain.md) です。図と domain.md が食い違ったら、domain.md に合わせて図を直します。
- 図には、仕様に書かれていることと、今の実装（コード）に書かれていることだけを描いています。決まっていないところは、図の中か補足に、未決事項（[open-issues.md](../open-issues.md)）や、やることリスト（[backlog.md](../backlog.md)）の番号を書いています。
- 仕様やコードを変えたときは、関係する図も合わせて直します。

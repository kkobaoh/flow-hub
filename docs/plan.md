## 1d：消耗品の管理・搬送計画とのつなぎ込み

装置・ステーション・上位システムとのやり取りの方式（未決事項 #11）は決まっていないので、どれも **ポート（インターフェース）と偽物** で作ります。

| 小ステップ | 内容 | 状態 |
|---|---|---|
| 1d-1 在庫の所在と受け渡し | 消耗品ごとの所在を持つ。配車の「搬送の許可を出してほしい」を受けて装置・ステーションに許可を出し、受け渡しの完了で所在を更新して配車に伝える | 済み |
| 1d-2 搬送計画 | 不足と回収の判断から、搬送の要求（1往復ぶん）を作って配車に頼む | 済み |
| 1d-3 装置からの通知 | 加工部への取り込み（中古品にする）、ストッカーに戻した、廃棄リクエスト、段取り替えのリクエスト、ID の照合のエラー、人が現物を交換した | 済み |
| 1d-4 ステーションと補充 | 入ってきた消耗品の ID の読み取り（所在不明の確定を含む）、ステーションの「不明な消耗品」と人による修正、出庫、上位システムへの補充のリクエスト | 済み |
| 1d-5 AGV での交換 | 画面からの指示で、照合が合わなかった消耗品をステーションへ回収し、ユーザーが選んだ消耗品を届ける（回収が先） | 済み（入れるスロットの優先順位は、やることリスト #14 に積んだ） |

## DB（構成のデータの保存）

起動するときに DB から構成のデータを読み、実行中に変わる構成のデータ（ストッカーの設定、キャリアの高さ、コマンドの番号）を DB に書きます。

- 動いている間の状態（**消耗品の在庫と所在**、予約、搬送、AGV の位置など）の保存は、未決事項 #14（再起動したときの状態の復元）を決めてから行います。それまでは、再起動すると消えます。
- 画面がない間は、開発とデバッグ用の **初期データの JSON ファイル** を用意し、起動したときに DB が空なら、それを入れます。
- マップは、公開した版を **すべて番号を付けて残し**、起動したときは **一番新しい版** を使います。版を切り替えるタイミングは、マップの編集（backlog #5）に取りかかるときに決めます。

| 小ステップ | 内容 | 状態 |
|---|---|---|
| DB-1 土台 | EF Core、PostgreSQL と SQLite の切り替え、コンテキストごとの DbContext（スキーマ、または SQLite の別ファイル） | 済み |
| DB-2 マップ | 公開したマップの版、キャリアの高さ | 済み（PostgreSQL での統合テストは backlog #15） |
| DB-3 交通整理と配車 | AGV と AGV の種類（速さ、キャリアの種類、充電の設定値）、コマンドの番号 | 済み（PostgreSQL での統合テストは backlog #15） |
| DB-4 消耗品の管理 | 装置、ステーション、加工の種類、品種、ストッカーの設定、入庫の予定（ID と品種の対応） | 済み（PostgreSQL での統合テストは backlog #15） |

## 全台の経路の計画とコントロールステータス

確認待ち A3（予約が道を塞ぐ）から、全台の経路をまとめて計画する作りに見直すことになりました。仕様は domain.md の「デッドロックの防止」「全台の経路の計画」「コントロールステータス」にあります。

| 小ステップ | 内容 | 状態 |
|---|---|---|
| PP-1 PathPlanning の土台 | 新しいコンテキスト `FlowHub.PathPlanning`（状態を持たない計算。何にも依存しない）。入力と出力の型、依存の表とアーキテクチャテストの更新 | 済み |
| PP-2 止まらない計画 | 順番を付けて、先の AGV から時刻つきで経路を決める。固定する部分（渡した指示、止まった AGV）、計画が立てられない AGV の見分け | 済み |
| PP-3 通る順番の守らせ方 | 交通整理が PathPlanning を呼び、パネルごとの通る順番を守らせて、区間ごとに予約する。頼みのたびに全台を立て直す | 済み |
| PP-4 止まった AGV と邪魔な AGV | 止まった AGV を障害物にして立て直す（異常はすぐ、緊急停止中は1分）。動かせる状況の邪魔な AGV を待機パネルへ動かす | 済み |
| PP-5 計画の改善 | 時間の上限（200ミリ秒）までの改善 | 済み |
| CS-1 5つのステータス | ステータスの持ち方、切り替えの条件、ステータスごとの振る舞い（割り当て、充電、全台の計画での扱い、受け付けるコマンド） | 済み |
| CS-2 DB への保存 | コントロールステータスを再起動しても残す。新しく登録した AGV は切り離しから始める | **次** |
| CS-3 マニュアルのコマンド | 行き先の指定と、1つずつの動作 | |

## 1d：消耗品の管理・搬送計画とのつなぎ込み

装置・ステーション・上位システムとのやり取りの方式（未決事項 #11）は決まっていないので、どれも **ポート（インターフェース）と偽物** で作ります。

| 小ステップ | 内容 | 状態 |
|---|---|---|
| 1d-1 在庫の所在と受け渡し | 消耗品ごとの所在を持つ。配車の「搬送の許可を出してほしい」を受けて装置・ステーションに許可を出し、受け渡しの完了で所在を更新して配車に伝える | 済み |
| 1d-2 搬送計画 | 不足と回収の判断から、搬送の要求（1往復ぶん）を作って配車に頼む | 済み |
| 1d-3 装置からの通知 | 加工部への取り込み（中古品にする）、ストッカーに戻した、廃棄リクエスト、段取り替えのリクエスト、ID の照合のエラー、人が現物を交換した | **次**（廃棄リクエストは 1d-2 で済み） |
| 1d-4 ステーションと補充 | 入ってきた消耗品の ID の読み取り（所在不明の確定を含む）、ステーションの「不明な消耗品」と人による修正、出庫、上位システムへの補充のリクエスト | 補充のリクエストは 1d-2 で済み |
| 1d-5 AGV での交換 | 画面からの指示で、照合が合わなかった消耗品をステーションへ回収し、ユーザーが選んだ消耗品を届ける（回収が先） | |
